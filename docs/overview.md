# Entra Task Assignments

## Overview
Entra Task Assignments gives coordinators a focused workspace to find colleagues in Microsoft Entra and assign clear, trackable work without maintaining a duplicate people directory.

## Users
Task coordinators and team leads search for a person by display name, select an assignee, create a task, and maintain its status.

## Core workflow
- Search the live organization directory by display name.
- Select one person and enter a title, description, and due date.
- Review assignments, update status, and remove tasks when needed.

## Design direction
A refined utilitarian workspace with a blue productivity palette, compact information-rich cards, strong search affordances, and accessible semantic color in light and dark themes.
